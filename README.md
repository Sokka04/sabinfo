# SabInfo — Reportage « Les détritus à Lomé »

Site WordPress One-Page **SabInfo** (thème natif **Twenty Twenty-Five** + blocs natifs Gutenberg) dédié au reportage vidéo sur les détritus à Lomé.

## Lancer le site en local (Laragon)

1. Cloner ce dépôt dans `C:\laragon\www\sabinfo`.
2. Copier `wp-config-sample.php` en `wp-config.php` et renseigner vos accès MySQL locaux (`DB_NAME = 'sabinfo'`).
3. Créer la base de données `sabinfo` dans MySQL et importer le fichier `database/sabinfo.sql`.
4. Ouvrir `http://localhost/sabinfo/` (administration : `http://localhost/sabinfo/wp-admin/`).
